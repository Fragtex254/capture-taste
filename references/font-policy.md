## 为什么字体需要单独处理

字体不是普通的装饰资源。

它会直接影响：

- 字符轮廓；
- 字宽与换行；
- 标题占据的视觉面积；
- 行高与阅读密度；
- 字重层级；
- 页面节奏；
- 品牌气质；
- 按钮、导航和卡片尺寸。

因此，Capture Taste 不应默认隔离目标字体，也不应默认复制目标字体。

字体必须作为一个独立决策处理。

## 支持的策略

### `ask`

在分析开始前让用户选择：

1. 沿用目标字体；
2. 使用相近替代字体；
3. 由 Skill 根据许可情况自动决定。

如果用户没有回答或当前环境不适合提问，则退化为 `auto`。

### `preserve`

尽量沿用目标字体。

仅在满足以下任一条件时允许：

- 系统字体；
- 明确的开源字体；
- Google Fonts 等具有清晰许可的公开字体；
- 用户已经合法拥有并提供的字体；
- 项目仓库中已经合法存在的字体。

不得：

- 从网页中提取并重新分发未知许可的字体文件；
- 将仅限网站使用的字体自动复制到新项目；
- 假设能在浏览器加载就等于允许商用或再分发。

### `substitute`

不使用原字体。

必须提取并记录原字体的：

- 衬线或无衬线；
- 字面宽度；
- x-height；
- 笔画粗细；
- 笔画对比；
- 字腔开放程度；
- 端点形态；
- 圆润或锐利程度；
- 几何或人文倾向；
- 字重范围；
- 字号与行高比例；
- 字距；
- 中英文混排特征；
- 数字与标点特征。

然后提供：

- 首选替代字体；
- 次选替代字体；
- 系统字体回退；
- 每个替代方案的相似点与差异；
- 替换后需要重新校准的排版参数。

### `auto`

按以下顺序判断：

1. 系统字体：允许沿用。
2. 明确开源或许可清晰的公开字体：允许沿用，并记录来源。
3. 用户已提供或项目已合法拥有的字体：允许沿用。
4. 许可不明、商业字体或仅能从网站资源中发现：切换为替代字体。

## 字体识别

记录：

- CSS `font-family`；
- 实际生效字体；
- 字重；
- 字体来源 URL 或 CSS；
- `@font-face` 声明；
- 本地字体或系统字体状态；
- WOFF、WOFF2、TTF、OTF 等格式；
- 许可信息是否明确；
- 是否包含中文；
- Variable Font 轴；
- Fallback 链。

无法确认许可时，标记为：

```text
license_status: unknown
reuse_allowed: false
```

## 后续 Agent 的行为

后续 Agent 必须：

1. 读取 `transfer/font-decision.md`；
2. 不得自行改变字体策略；
3. 在 `preserve` 模式下，只从已批准来源安装字体；
4. 在 `substitute` 模式下，使用指定替代字体；
5. 字体发生变化后，重新检查换行、字号、行高和容器宽度；
6. 在视觉验收中检查字体形态，而不只是字体名称；
7. 不得把字体文件提交到仓库，除非 Taste Pack 明确允许。
